Expand description

Creates a new poller that will periodically poll fun with the specified period on the current SPDK thread.

§Notes

The granularity of period is microseconds. If the period is zero or less than 1μs, the polled will be polled as fast as possible.

§Panics

This function panics if the duration cannot be represented as a unsigned 64-bit integer.
