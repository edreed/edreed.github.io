Infrastructure and abstractions supporting asynchronous execution on SPDK threads.

An SPDK thread is a lightweight, stackless thread of execution and does not necessarily correspond 1:1 with a posix thread. Instead, a lower-level framework like the SPDK Event Framework polls each SPDK thread for work. This allows the SPDK Event Framework to multiplex many SPDK threads on a smaller number of posix threads. In this crate, the SPDK thread is implemented by the Thread type.

There are two mechanisms for scheduling work on an SPDK thread: messages and pollers. A message consists of a function object sent via the Thread::send_msg function. A poller is a type implementing the Polled trait that has its Polled::poll method called periodically.

See Message Passing and Concurrency for more details on the SPDK threading model.
