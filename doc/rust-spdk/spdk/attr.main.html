Attribute Macro main 

#[main]
Expand description

Marks the main entry point of an application using the SPDK Application Framework.

§Notes

This macro is for applications that do not require a complex setup. Consider using Builder to create a Runtime directly if this macro does not meet your needs.

The Runtime created by this macro is initialized from the command line arguments supported by the spdk_app_parse_args function.

§Attributes

The cli_args attribute is used with the Parser trait to specify the parsing function for a struct defining command-line arguments. See the Parser derive macro for more information.

§Usage

#[spdk::main]
async fn main() {
    println!("Hello, World!");
}
