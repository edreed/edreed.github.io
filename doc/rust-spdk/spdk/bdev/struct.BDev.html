Struct BDev 

Source 
pub struct BDev<T>(/* private fields */)
where
    T: AsRawBDev;
Available on crate feature bdev only.
Expand description

Represents a block device.

The type T determines how the BDev manages the underlying spdk_bdev lifetime. If T implements OwnedOps it means that the BDev is responsible for managing the lifetime of the underlying spdk_bdev. The BDev::destroy() method must be used to explicitly destroy the device when it is no longer needed. BDev instances that own the lifetime of the underlying spdk_bdev can be shared with other SPDK threads by reference safely and are therefore Sync as long as T is also Sync. Since the BDev::destroy() method must be called on the thread on which the block device was created, it is not Send.

If T does not implement OwnedOps (e.g. OwnedBy and Any), the BDev does not manage the lifetime of the underlying spdk_bdev and may be shared by reference or by value across threads safely. It is both Send and Sync in this case as long as T is also Send and Sync.

impl BDev<Any>

pub fn from_name(name: &CStr) -> Result<BDev<Any>>

Get a BDev by its name.

A BDev<Any> instance is a non-owning reference to the underlying spdk_bdev instance. It ensures that the underlying spdk_bdev remains valid for the lifetime of the BDev<Any> instance but cannot destroy it. However, a call to BDev::destroy() by another task will be deferred until all BDev<Any> instances referencing the same spdk_bdev are dropped.

§Returns

This method returns Ok(dev) if the device exists and Err(ENODEV) if no block device with the given name exists. It may return other errors if initialization of the BDev<Any> instance fails. See Any for details.
